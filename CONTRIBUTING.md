# Contribution policy

JM ProjectOP is a proprietary project. Please do not open unsolicited public
pull requests containing third-party code or game assets.

Participation requires explicit authorization from the project owner and,
when appropriate, a separate written agreement covering intellectual property,
confidentiality and permissions for submitted materials.

Do not assume that a GitHub pull request or access grant constitutes acceptance
of a contribution or transfer of rights.

For product scope, see [docs/PRODUCT_SPEC.md](docs/PRODUCT_SPEC.md).
