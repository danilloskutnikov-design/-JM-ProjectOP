# JM ProjectOP — приложение (Windows, затем Mac, затем Android)

## Что это
Окно с интерфейсом: инструкция → автоигра → монтаж → предпросмотр → MP4. Движок тот же, что в `packages/` (покрыт тестами); приложение — локальный сервер + один HTML-интерфейс (`app/ui/`). Окно Windows/Mac — Electron, который открывает этот интерфейс и приносит свои Node и ffmpeg, поэтому на машине пользователя ничего ставить не нужно.

Данные: `Документы/JM ProjectOP/` — `projects/` (сохранённые проекты), `exports/` (готовые MP4), `assets/` (сюда можно класть свои JSON-ассеты, они подхватятся при запуске).

## Как запустить сейчас (без установщика)
Нужны Node ≥ 22.18 и ffmpeg. Двойной клик по `start-app.bat` (Windows) / `start-app.command` (Mac) / `./start-app.sh` (Linux). Откроется браузер с приложением; закройте окно консоли, чтобы остановить.

## Как получить установщик Windows (.exe)
Вариант А — на своём Windows-компьютере:
1. Установить Node.js 22 (nodejs.org).
2. В папке проекта: `npm install`, затем `npm run dist:win`.
3. Установщик и portable-версия появятся в `release/`.

Вариант Б — без установки чего-либо, через GitHub: вкладка *Actions* → *Build desktop apps* → *Run workflow*. Через несколько минут в результатах (*Artifacts*) будут `.exe` для Windows и `.dmg` для Mac. Тот же workflow срабатывает на тег `v*`.

Сборки **не подписаны**: Windows SmartScreen покажет «Неизвестный издатель» («Подробнее» → «Выполнить в любом случае»); на Mac — правый клик → «Открыть». Подпись требует сертификатов.

## Проверки
- `npm test` — 35 тестов движка.
- `npm run test:smoke` — компилирует приложение и проверяет его обычным Node: API, токен, защита от чужих сайтов, предпросмотр, Range для видео.
- `npm run test:ui` — прогон интерфейса в настоящем Chromium (нужен `playwright`).

## Безопасность локального сервера
Слушает только 127.0.0.1, принимает только Host `localhost`/`127.0.0.1`, а API и видео требуют случайный токен запуска — чужая веб-страница не сможет им управлять.

## Что пока не готово
- На Windows проверены Electron-окно и собранная portable-версия (ролик, предпросмотр, экспорт MP4 со встроенным ffmpeg). NSIS-установщик проверен тихой установкой и удалением. Mac-сборка ещё не прогонялась. Иконка — стандартная Electron.
- Ассеты — только процедурные JSON. Импорт PNG/JPG (фоны, наклейки, чехол) — следующий шаг.
- Smooth-loop, камера, переходы, моды, MCP — не реализованы.

## Mac
Тот же код и `npm run dist:mac` (или workflow). Отдельной работы почти нет, кроме подписи/нотаризации.

## Android (не начат)
Electron на Android не работает. Путь: вынести движок в клиент — симуляция, бот, монтаж и рендерер уже написаны на чистом TS без Node-API; заменить нужно только экспорт (ffmpeg → WebCodecs `VideoEncoder` + MP4-муксер), хранение (файлы → IndexedDB) и серверный слой (вызовы напрямую из интерфейса), тяжёлое вынести в Web Worker, обернуть Capacitor'ом в APK. Тот же интерфейс. Побочный бонус — PWA, устанавливаемая на любой ОС. Риск: скорость программного рендера на телефоне, придётся измерять.
