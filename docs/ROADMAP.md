# JM ProjectOP — roadmap

Документ описывает **план**, а не готовые функции. Критерии основаны на [продуктовом ТЗ](PRODUCT_SPEC.md).

## Milestone 0 — Foundation

- [ ] Утвердить правообладателя кода и разрешения на использование Phone Case и JUSTMOBY.
- [x] Создать репозиторий и первичную документацию.
- [x] Добавить фирменную графику и проприетарное уведомление.
- [ ] Закрыть доступ к исходникам (private) и настроить права участников.
- [ ] Утвердить стек, структуру проекта, контракт сценария и формат проекта.

## Milestone 1 — Phone Case runtime

- [ ] Загрузка и конфигурация разрешённых ассетов.
- [ ] Воспроизведение очистки, рисования, наклеек, финала.
- [ ] Контроллер автопрохождения и настройки последовательности/скорости.
- [ ] Экспорт событий, исходных состояний и логов с таймкодами.
- [ ] Повтор дубля и тайм-аут/диагностика.

## Milestone 2 — Event-driven edit

- [ ] Редактор/импорт текстового сценария и проверка плана.
- [ ] Монтаж по явным событиям и правилам этапов.
- [ ] Отсечение неинформативных фрагментов.
- [ ] Работа с недостаточным материалом (дубль/ошибка).
- [ ] Монтажный план с возможностью перестановки/замены/ретайминга.

## Milestone 3 — Editable output

- [ ] Формат сохранения/открытия редактируемого проекта.
- [ ] Замена ассетов и атрибутов сцен после монтажа.
- [ ] Отслеживание зависимостей, пересчёт и повторный рендер только затронутых эпизодов.
- [ ] Пресеты Onboard и Paywall, направляющие сейвзон и управляемое пространство под крестик.

## Milestone 4 — Delivery

- [ ] Cut loop и smooth loop.
- [ ] MP4 H.264 30 FPS без обязательного аудио.
- [ ] Пакетная сборка вариантов.
- [ ] Три последовательных повтора каждого типа цикла без дефектов.
- [ ] Сравнение экспорта с предпросмотром.
- [ ] Рабочая сборка, образец проекта и инструкция.

## Definition of Done V1

Принимается только результат, который проходит **все** критерии из раздела 8 [PRODUCT_SPEC.md](PRODUCT_SPEC.md). Скриншоты, статические мокапы и README не считаются реализацией.
