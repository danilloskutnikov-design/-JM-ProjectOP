# ADR 0001 — Стек и среда выполнения

**Статус:** принято (прототип 0.1)

- **Язык:** TypeScript, исполняется напрямую Node ≥ 22.18 (type stripping), без сборки. Допускается только «стираемый» синтаксис (`erasableSyntaxOnly`): без enum, namespace и parameter properties.
- **Рендер:** собственный программный растеризатор (`packages/render`), без Node-зависимостей в самом рендерере, поэтому код пригоден и для браузера. Один и тот же код даёт превью и MP4: это основа требования «MP4 соответствует предпросмотру».
- **Экспорт:** покадровый вывод RGBA в `ffmpeg` (H.264, yuv420p, 30 FPS, без звука). Захват экрана не используется.
- **Зависимости:** только dev (`typescript`, `@types/node`).
- **Позже:** PixiJS/WebGL и UI-оболочка (Tauri/Electron) поверх тех же пакетов; решение пересматривается, если программный рендер станет узким местом (сейчас ≈ 28 с на 336 кадров 1124×1124).
