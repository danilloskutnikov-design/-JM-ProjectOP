# ADR 0004 — Формат проекта и ключи этапов

**Статус:** принято

**Формат:** один JSON со `schemaVersion: 1`: пресет (с пользовательской `quietZone`), сценарий, сцена (ссылки на ассеты по id), дубли, таймлайн, `loop`, `modLock`. Ассеты в проект не встраиваются; корень ассетов настраивается (`PROJECTOP_ASSETS`), потому что лицензированные файлы Phone Case не хранятся в репозитории.

**Ключ этапа** — цепочечный хеш: `key[i] = H(key[i-1], этап, параметры, keyParts этапа)`. Этап сам объявляет зависимости (`StageImpl.keyParts`). Поэтому:

| Правка | Что пересимулируется |
|---|---|
| рисунок | draw, stickers, reveal |
| наклейки / их позиции | stickers, reveal |
| фон, цвет чехла, quiet zone, длительности | ничего (только рендер) |
| seed сцены, пресет | всё |

Дубль годен для этапа `i`, если ключи `0..i` совпадают с текущими и этап завершён. Нехватку материала утилита не маскирует: `needsRetake` с причиной `STALE`/`MISSING`, рендер отказывается работать, пока этап не перегенерирован.
